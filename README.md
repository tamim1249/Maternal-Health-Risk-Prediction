# Data

The datasets are public and are not redistributed here. Download them and place the CSV files in this folder:

| File | Source |
| --- | --- |
| `Maternal Health Risk Data Set.csv` | [Kaggle](https://www.kaggle.com/datasets/csafrit2/maternal-health-risk-data) · [UCI ML Repository](https://archive.ics.uci.edu/dataset/863/maternal+health+risk) (doi:10.24432/C5DP5D) |
| `fetal_health.csv` | [Kaggle](https://www.kaggle.com/datasets/andrewmvd/fetal-health-classification) · derived from the [UCI Cardiotocography dataset](https://archive.ics.uci.edu/dataset/193/cardiotocography) |

Expected shapes: maternal 1,014 × 7, fetal 2,126 × 22. Other locations can be passed with `--maternal` and `--fetal`.
